# Music Station

사용자가 음원을 업로드하고 다른 사용자의 음악을 재생할 수 있는 음악 공유 서비스입니다. 여러 웹 애플리케이션으로 역할을 나누어 개발한 ITWILL 국비지원 교육과정 팀 프로젝트입니다.

## 프로젝트 정보

- 기간: 2023.10.18 ~ 2023.11.01
- 인원: 4명
- 교육과정: ITWILL 국비지원 교육과정
- 담당 역할
  - 음악 재생 및 재생목록
  - 메인 페이지와 TOP100
  - 로그인 / 회원가입
  - 팀원 코드 통합

## 기술 스택

### Backend

- Java 8
- Servlet / JSP / JSTL
- MyBatis
- Oracle

### Frontend

- HTML / CSS
- JavaScript
- jQuery / AJAX

## 주요 기능

- 하단 재생 컨트롤러를 통한 음악 재생 제어와 재생목록 관리
- 음원, 이미지, 제목, 설명을 함께 등록하는 음악 업로드
- 역대 및 주간 TOP100 조회
- 로그인 / 회원가입

### 음악 재생 및 재생목록

## 문제 해결 경험

### TOP100 조회 성능 저하

**문제**
재생 로그가 늘어나면서 조회수를 기준으로 순위를 계산하는 데 5초 이상 걸렸습니다.

**원인**
요청 시점마다 순위 데이터를 계산하는 방식은 재생 로그가 증가할수록 조회 부담이 커졌습니다.

**해결**
애플리케이션 시작 시 `Timer`로 역대·주간 TOP100을 계산하고, 이후 약 5분마다 DB 조회 결과로 메모리의 리스트를 갱신했습니다. TOP100 페이지와 메인 페이지는 갱신된 리스트를 참조하도록 구성했습니다.

**결과**
사용자 체감 응답 시간을 5초 이상에서 1초 미만으로 개선했습니다.

### 업로드 파일 반영 지연

**문제**
업로드 파일을 프로젝트 내부 리소스 경로에 저장하면서 새 파일이 서비스에 인식되기까지 약 10초가 걸렸습니다.

**대응과 학습**
당시에는 원인을 해결하지 못해 업로드 후 약 10초 뒤 반영된다는 안내를 제공했습니다. 이후 [Cabbage Market](https://github.com/jsw4795/Cabbage_Market)에서 같은 문제를 다시 분석했고, 외부 리소스 경로와 Tomcat Context 설정으로 즉시 반영되도록 해결했습니다.

### 프로젝트 간 세션 attribute 공유

**문제**
하나의 Tomcat에서 나누어 운영한 여러 프로젝트 사이에서 세션 attribute를 공유할 수 없었습니다.

**해결**
Tomcat의 `crossContext`와 `emptySessionPath`를 설정하고, `ServletContext`를 통해 `/frame` 컨텍스트에 저장한 attribute를 다른 프로젝트에서 조회하도록 구성했습니다.

**결과**
한 프로젝트에서 저장한 로그인 관련 attribute를 다른 프로젝트에서도 참조할 수 있게 했습니다.
